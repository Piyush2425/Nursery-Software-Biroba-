## 📥 सॉफ्टवेअर डाऊनलोड कसे करावे (How to Download & Run)

ग्राहकांना सॉफ्टवेअर वापरण्यासाठी खालीलपैकी कोणताही एक पर्याय निवडा:

### पर्याय १: थेट .exe फाईल (Direct Executable - 19 MB)
1. **[Shree-Biroba-Nursery.exe](https://github.com/Piyush2425/Nursery-Software-Biroba-/raw/main/Shree-Biroba-Nursery.exe)** या फाईलवर क्लिक करून **Download** दाबा.
2. डाऊनलोड झालेली `.exe` फाईल तुमच्या कॉम्प्युटरवर कुठेही ठेवा (उदा. Desktop किंवा D: Drive).
3. त्यावर डबल-क्लिक करून सॉफ्टवेअर सुरू करा! (कोणतीही इन्स्टॉलेशनची गरज नाही).

### पर्याय २: संपूर्ण पॅकेज झिप फाईल (Full Package .ZIP)
1. **[BirobaNursery-FullPackage.zip](https://github.com/Piyush2425/Nursery-Software-Biroba-/raw/main/BirobaNursery-FullPackage.zip)** डाउनलोड करा.
2. झिप फाईल Unzip / Extract करा आणि `NurseryBilling.App.exe` वर डबल-क्लिक करा.
